# BC-10.03.001: Privacy-Config-Contract Is Generated and Machine-Gated for Default-High-Privacy Settings

## Description

The factory generates a `privacy-config-contract` that specifies and machine-validates
default privacy settings for the game build: geolocation off by default, profiling off
by default, no dark-pattern lint failures in consent UIs, age-gate present with per-region
digital-consent-age configuration, and VPC/separate-consent flow presence for
child-directed builds. The data-collection inventory (derived from `telemetry-event-taxonomy`)
is cross-checked against the privacy policy. Adequacy of lawful basis and "is this game
child-directed?" remain human-legal gates (RED items). Sources: UK ICO Children's Code,
GDPR Art 8, FTC COPPA 2025 amendment (compliance deadline 22 April 2026; effective
23 June 2025, per Federal Register 2025-05904).

## Preconditions

1. A `telemetry-event-taxonomy` exists for the game declaring all telemetry events, SDK
   dependencies, and data recipients (from qa-testing-liveops.md pattern).
2. A `game-profile` exists with `target_regions[]` and `child_directed_inputs`.
3. The runtime/configuration system for the game supports per-region feature flags
   (or the factory can declare the intended defaults in a config artifact).
4. COPPA 2025 compliance deadline (22 April 2026) is within the game's projected ship window.

## Behavior

1. Factory reads `telemetry-event-taxonomy` to build a `data-collection-inventory`:
   `{event_name, data_fields_collected[], recipient_sdks[], purpose}` for every event.

2. Factory generates `privacy-config-contract` artifact (JSON):
   ```json
   {
     "game_id": "<id>",
     "build_version": "<version>",
     "data_collection_inventory": [...],
     "default_settings": {
       "geolocation": "off",
       "profiling": "off",
       "third_party_ad_tracking": "off",
       "social_features": "restricted_by_default"
     },
     "age_gate": {
       "present": true,
       "per_region_consent_ages": {
         "EU_default": 16,
         "DE": 16, "FR": 15, "AT": 14, "BE": 13, "BG": 14,
         "US_COPPA": 13,
         "UK": 13
       },
       "consent_age_source": "GDPR-Art8-FRA-mapping + FTC-COPPA-2025-amendment"
     },
     "vpc_flow_present": true|false,
     "separate_consent_third_party_ads": true|false,
     "dark_pattern_lint_status": "PASS|FAIL|NOT_CHECKED",
     "dark_pattern_lint_findings": [],
     "coppa_2025_compliance_flags": {
       "biometric_pii_handled": true|false,
       "gov_id_pii_handled": true|false,
       "data_retention_policy_declared": true|false,
       "security_program_declared": true|false
     },
     "human_legal_gates": [
       "lawful_basis_adequacy",
       "dpia_reasoning",
       "child_directed_determination",
       "best_interests_of_child_dpia"
     ]
   }
   ```

3. Machine-validate the following GREEN checks:
   - `default_settings.geolocation == "off"`: PASS/FAIL
   - `default_settings.profiling == "off"`: PASS/FAIL
   - `age_gate.present == true`: PASS/FAIL
   - `vpc_flow_present == true` if `child_directed_inputs` suggests possible child audience: PASS/FAIL
   - `separate_consent_third_party_ads == true` if any ad SDK in `data_collection_inventory`: PASS/FAIL
   - Dark-pattern lint on consent UI code (if consent UI source is present): look for pre-checked boxes,
     confusingly-worded decline buttons, dark-pattern patterns.
   - Privacy policy present and contains all inventory-declared data recipients (cross-check).

4. Any GREEN check FAIL → `privacy_config_status: FAIL`.
5. All GREEN checks PASS → `privacy_config_status: PASS` (human_legal_gates remain as human tasks).

## Postconditions

- `privacy-config-contract` exists at `.factory/artifacts/compliance/<game_id>/privacy-config-contract-<build_version>.json`.
- Schema validates against `privacy-config-contract-v1.schema.json`.
- Every telemetry event in `telemetry-event-taxonomy` appears in `data_collection_inventory`.
- `default_settings.geolocation` and `default_settings.profiling` are present and set to `"off"`.
- `human_legal_gates` array is non-empty (adequacy questions always require human review).

## Invariants

- INV-1: `default_settings.geolocation` and `default_settings.profiling` are NEVER set
  to `"on"` as defaults. If the game requires them, the privacy-config-contract FAILS and
  a human-legal review is required to document lawful basis.
- INV-2 (COPPA 2025): If the game has any ad SDK in `data_collection_inventory` and targets
  regions where COPPA 2025 applies, `separate_consent_third_party_ads` must be `true`.
  Missing it is a GREEN FAIL.
- INV-3: "Is this game child-directed?" is ALWAYS `human_legal_gates[0]`; the factory
  supplies `child_directed_inputs` but never makes the determination.
- INV-4: The digital-consent age table uses the FRA mapping for EU member states; any state
  not in the mapping defaults to 16 (conservative).
- INV-5: The `data_collection_inventory` must include EVERY telemetry SDK, not just factory-
  generated events. Third-party crash-reporting SDKs, analytics, and ad networks are included.

## Edge Cases

| EC-ID | Scenario | Expected Result |
|-------|----------|----------------|
| EC-001 | Telemetry taxonomy is empty (no events declared) | `data_collection_inventory: []`; privacy policy cross-check trivially passes; warning: "No telemetry events declared — ensure all SDK data collection is declared" |
| EC-002 | Game requires geolocation as a core feature (e.g., location-based AR game) | GREEN FAIL: "default_settings.geolocation must be 'off' by default; game must implement opt-in for location use"; human-legal review required to document lawful basis |
| EC-003 | Ad SDK present but `separate_consent_third_party_ads: false` | GREEN FAIL: "COPPA 2025 / GDPR-K: separate consent required for third-party ad disclosure when ad SDK detected" |
| EC-004 | Consent UI has a pre-checked marketing-consent checkbox | Dark-pattern lint FAIL: "Pre-checked consent checkbox violates UK Children's Code / GDPR dark-pattern prohibition" |
| EC-005 | COPPA 2025 compliance deadline 22 April 2026 — build date is before deadline | `coppa_2025_compliance_flags` evaluated; warning if any flag is `false` |
| EC-006 | Game targets no regions with child-directed obligations | `vpc_flow_present` check is N/A; `age_gate` evaluated for declared regions only |

## Canonical Test Vectors

| Config state | `geolocation` default | `age_gate.present` | Expected `privacy_config_status` |
|-------------|----------------------|-------------------|----------------------------------|
| All defaults off, age gate present, no ad SDKs | `off` | true | `PASS` |
| Geolocation default left as `on` | `on` | true | `FAIL` |
| Ad SDK present, `separate_consent_third_party_ads: false` | `off` | true | `FAIL` |
| Consent UI has pre-checked checkbox | `off` | true | `FAIL` (dark-pattern lint) |
| All GREEN pass; human gates remain | `off` | true | `PASS` (human_legal_gates still pending) |

## Verification Properties

- VP-COMP-007: `default_settings.geolocation` is never `"on"` in an accepted privacy-config-contract.
- VP-COMP-008: `human_legal_gates` is never empty; at minimum contains `child_directed_determination`.
- VP-COMP-009: Every SDK in `telemetry-event-taxonomy` appears in `data_collection_inventory`.
