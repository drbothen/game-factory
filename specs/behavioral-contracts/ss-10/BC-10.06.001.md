# BC-10.06.001: Human-Gated Ratings Submission Terminal Step Is Surfaced with Complete Evidence Package

## Description

IARC ratings submission, final rating application to individual storefronts, and
compliance sign-off (legal-doc review, adequacy judgments) are human-gated terminal steps
that the factory never performs autonomously. After completing the full machine-checkable
compliance battery (BCs 10.01–10.05), the factory surfaces a structured
`human-gated-compliance-task` record containing the complete evidence package: the
`ratings-submission-manifest`, `compliance-checklist`, `privacy-config-contract`,
`legal-doc-set`, and `ai-disclosure-manifest`. The compliance dimension of the convergence
model remains DEGRADED-PENDING until the responsible human marks all tasks complete. This BC enforces
DI-006 for the compliance pipeline.

## Preconditions

1. All machine-checkable compliance artifacts for the build version exist:
   - `ratings-submission-manifest` (BC-10.01.001): `status ∈ {auto_filled_partial, auto_filled_partial_with_warnings}` — both statuses are accepted; `auto_filled_partial_with_warnings` indicates an E-COMP-012 NFT field divergence was detected and must be resolved before final IARC submission (see Task A checklist item and EC-006)
   - `compliance-checklist` (BC-10.02.001): `privacy_config_status: PASS`
   - `privacy-config-contract` (BC-10.03.001): `privacy_config_status: PASS`
   - `legal-doc-set` (BC-10.04.001): `overall_status: STRUCTURALLY_COMPLETE`
   - `ai-disclosure-manifest` (BC-10.05.001): `overall_disclosure_status: COMPLETE|PARTIAL`
2. The `compliance-checklist` contains no unresolved GREEN FAIL items.
3. The `convergence-report` has a writable `dimensions.provenance_legal_compliance` field.

## Behavior

1. Factory generates `human-gated-compliance-task` record(s):

   **Task A — Ratings Submission:**
   ```json
   {
     "task_id": "COMPLIANCE-RATINGS-<game_id>-<build_version>",
     "task_type": "iarc_ratings_submission",
     "responsible_role": "compliance-officer",
     "status": "outstanding",
     "task_title": "IARC Ratings Submission: <game_id> v<build_version>",
     "description": "Submit the IARC questionnaire for <game_id>. The factory has auto-filled all objective questions. Complete the content-intensity questions that require human judgment and submit via the applicable storefront's IARC flow.",
     "artifacts_required": [
       "ratings-submission-manifest: <path>",
       "compliance-checklist: <path>"
     ],
     "checklist": [
       "Review auto-filled objective answers in ratings-submission-manifest",
       "IF ratings-submission-manifest.status == 'auto_filled_partial_with_warnings': RESOLVE E-COMP-012 NFT field divergence (reconcile genre-profile.nft_mechanics with game-metadata-spec.nft_blockchain) BEFORE submitting — divergence means PEGI-18 was applied conservatively; confirm correct PEGI minimum with legal/ratings team before submission",
       "Verify PEGI-2026 predicted minimum age matches intended audience; escalate if conflict",
       "Answer all REQUIRES_HUMAN_ANSWER questions (content intensity, violence level, etc.)",
       "Submit via storefront IARC flow (Google Play, Nintendo eShop, Microsoft Store, EGS, etc.)",
       "For PEGI standalone and ESRB physical: route to respective board separately if needed",
       "Mark task complete with storefront confirmation reference"
     ],
     "success_criterion": "IARC rating(s) received and applied to all target storefronts",
     "regulatory_deadline_note": "GRAC (South Korea) and USK (Germany, physical) are legally mandatory pre-release. Ensure ratings are obtained before public release in these regions.",
     "blocking": true
   }
   ```

   **Task B — Legal Document Review:**
   ```json
   {
     "task_id": "COMPLIANCE-LEGAL-<game_id>-<build_version>",
     "task_type": "legal_doc_review_sign_off",
     "responsible_role": "legal-counsel",
     "status": "outstanding",
     "task_title": "Legal Document Review and Sign-Off: <game_id>",
     "artifacts_required": [
       "legal-doc-set: <path>",
       "privacy-config-contract: <path>"
     ],
     "checklist": [
       "Review all DRAFT legal documents (EULA, ToS, Privacy Policy, region addenda)",
       "Verify lawful basis for GDPR data processing",
       "Complete DPIA if high-risk processing is present",
       "Verify child-directed determination and COPPA compliance posture",
       "Confirm privacy policy is consistent with data-collection-inventory",
       "Sign off on legal sufficiency",
       "Mark task complete"
     ],
     "success_criterion": "Qualified legal counsel has reviewed and approved all legal documents",
     "blocking": true
   }
   ```

   **Task C — AI Disclosure Review (if YELLOW items exist):**
   Generated only if `ai-disclosure-manifest.china_ai_label_manifest.status == "DRAFT_PENDING_REVIEW"`
   or `eu_c2pa_marks.coverage_status != COMPLETE`.

2. All tasks are added to `convergence-report.dimensions.provenance_legal_compliance.human_tasks[]`.
3. `convergence-report.dimensions.provenance_legal_compliance` is set to `DEGRADED-PENDING` (was already
   `DEGRADED-PENDING` from compliance-checklist pending items; remains `DEGRADED-PENDING` until all tasks complete).
4. The factory NEVER submits IARC questionnaire answers to any storefront or board.
5. The factory NEVER signs off on legal document sufficiency.

## Postconditions

- `human-gated-compliance-task` records exist for Task A (ratings) and Task B (legal review)
  for every game build that has passed the machine-checkable battery.
- All tasks have `status: outstanding` until a human marks them complete.
- `convergence-report.dimensions.provenance_legal_compliance != GREEN` while any task is outstanding.
- The ratings-submission-manifest, compliance-checklist, privacy-config-contract, legal-doc-set,
  and ai-disclosure-manifest paths are all present in the respective task `artifacts_required[]`.

## Invariants

- INV-1 (DI-006): Ratings submission task (Task A) and legal review task (Task B) are NEVER
  suppressed. Every compliance pipeline run that reaches the terminal step generates both tasks.
  Suppression is a hook-detectable defect.
- INV-2: The factory never submits to IARC, any rating board, or any storefront rating flow.
  It prepares the evidence package; the human submits.
- INV-3: Only the `compliance-officer` (Task A) and `legal-counsel` (Task B) roles may mark
  their respective tasks complete. No automated process may do so.
- INV-4: The regulatory deadline note (GRAC South Korea, USK Germany) is always present in
  Task A. It is a fixed warning, not a machine-checked deadline.

## Edge Cases

| EC-ID | Scenario | Expected Result |
|-------|----------|----------------|
| EC-001 | Compliance-checklist has unresolved GREEN FAIL items | Tasks are NOT generated; compliance pipeline is BLOCKED until GREEN FAILs are resolved; `convergence_report.dimensions.provenance_legal_compliance = BLOCKED` |
| EC-002 | Game only targets US and does not trigger USK/GRAC | Regulatory deadline note is still present (cautionary); human can note it as N/A |
| EC-003 | `ai-disclosure-manifest.overall_disclosure_status: BLOCKED` (DI-003 violation) | Tasks NOT generated; pipeline is BLOCKED at AI-disclosure step; error must be resolved first |
| EC-004 | Legal-doc-set structural status is INCOMPLETE | Task B generated with an additional checklist item: "Complete missing sections in legal documents before legal review" |
| EC-005 | Human marks Task A complete but Task B still outstanding | `convergence_report` remains `DEGRADED-PENDING`; Task B must also be complete for `GREEN` |
| EC-006 | `ratings-submission-manifest.status == auto_filled_partial_with_warnings` (E-COMP-012 NFT divergence) | Task A is generated and surfaced with a mandatory resolution checklist item; the compliance-officer MUST resolve the NFT field divergence (reconcile genre-profile.nft_mechanics vs game-metadata-spec.nft_blockchain) before marking Task A complete; `convergence_report` stays `DEGRADED-PENDING`; resolves the DI-006/DI-011 fail-open on the high-risk under-rating path |

## Canonical Test Vectors

| Compliance battery state | Tasks generated | `provenance_legal_compliance` dim |
|-------------------------|----------------|-----------------------------------|
| All GREEN PASS; ai-disclosure COMPLETE | Task A + Task B | DEGRADED-PENDING (tasks outstanding) |
| All GREEN PASS; manifest status = auto_filled_partial_with_warnings (E-COMP-012) | Task A + Task B (Task A has NFT divergence resolution gate) | DEGRADED-PENDING |
| Task A complete; Task B outstanding | Task A (complete), Task B (outstanding) | DEGRADED-PENDING |
| Both Task A and B complete | Both complete | GREEN |
| GREEN FAIL unresolved | None | BLOCKED |
| DI-003 violation in ai-disclosure | None | BLOCKED |

## Verification Properties

- VP-COMP-017: Every compliance pipeline run that transitions to terminal step generates at
  minimum Task A (ratings) and Task B (legal review).
- VP-COMP-018: No factory process sets any compliance task `status: complete`.
- VP-COMP-019: `convergence_report.dimensions.provenance_legal_compliance == GREEN` only when
  all outstanding compliance tasks are `status: complete`.
- VP-COMP-020: When `ratings-submission-manifest.status == auto_filled_partial_with_warnings`,
  Task A is generated (not suppressed) and its checklist contains the E-COMP-012 NFT divergence
  resolution item. No build with a `auto_filled_partial_with_warnings` manifest may have
  Task A absent — that would be the DI-006/DI-011 fail-open on the under-rating path.
