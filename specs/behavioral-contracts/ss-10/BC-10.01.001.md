# BC-10.01.001: IARC Objective-Questionnaire Auto-Fill from Game Metadata

## Description

The factory auto-fills the objective (machine-answerable) questions of the IARC
questionnaire from verifiable game metadata: the economy graph, content-descriptor tags,
feature flags, and monetization spec. Objective questions are those answerable from
declared game data without content-intensity judgment — presence of IAP, random-paid items,
user communication, location data, NFT/blockchain, gambling simulation, and PEGI-2026
interactive-risk features. Content-intensity questions (violence level, sexual content,
strong language) are flagged `REQUIRES_HUMAN_ANSWER`. The output is a
`ratings-submission-manifest` that drives storefront IARC submission. The ratings submission
terminal step is human-gated (BC-10.06.001). Regulatory source: IARC (globalratings.com).

## Preconditions

1. A `game-metadata-spec` exists for the game with declared fields:
   - `in_app_purchases: bool`
   - `random_paid_items: bool` (loot boxes, gacha, card packs)
   - `user_to_user_communication: bool`
   - `location_shared: bool`
   - `unrestricted_internet: bool`
   - `simulated_gambling: bool`
   - `real_money_gambling: bool`
   - `nft_blockchain: bool`
   - `time_limited_offers: bool`
   - `punitive_play_by_appointment: bool` (lose content/progress for not logging in)
   - `content_descriptors[]`: list of content tags (from `content-descriptor-contract`)
2. The factory has access to the declared IARC questionnaire schema version.
3. The PEGI 2026 interactive-risk category rule engine is loaded (effective June 2026).

## Behavior

1. For each objective IARC questionnaire question, the factory maps from `game-metadata-spec`:

   | IARC Question | Source field | Mapping |
   |---------------|-------------|---------|
   | In-App Purchases present? | `in_app_purchases` | Direct bool |
   | In-App Purchases include random/paid items? | `random_paid_items` | Direct bool |
   | User-to-User communication present? | `user_to_user_communication` | Direct bool |
   | Is user communication unrestricted? | `user_to_user_communication AND NOT has_block_report_tools` | Derived |
   | Location data shared? | `location_shared` | Direct bool |
   | Unrestricted internet access? | `unrestricted_internet` | Direct bool |
   | Simulated gambling? | `simulated_gambling` | Direct bool |
   | Real money gambling? | `real_money_gambling` | Direct bool |
   | NFT/blockchain mechanics? | `nft_blockchain` | Direct bool |
   | Time-limited/quantity-limited offers? | `time_limited_offers` | Direct bool |
   | Punitive play-by-appointment? | `punitive_play_by_appointment` | Direct bool |

2. For content-intensity questions (violence level, sexual content, drug references,
   strong language, horror, discrimination): emit `REQUIRES_HUMAN_ANSWER` with the
   question text and a content-classifier advisory note (non-authoritative).

3. Compute PEGI-2026 predicted minimum age from objective data:
   - `random_paid_items: true` → minimum_pegi ≥ 16
   - `nft_blockchain: true` → minimum_pegi = 18 (hard override)
   - `time_limited_offers: true` → minimum_pegi ≥ 12
   - `punitive_play_by_appointment: true` → minimum_pegi ≥ 12
   - `user_to_user_communication: true AND NOT has_block_report_tools: true` → minimum_pegi = 18
   - (Higher value from all rules wins; default minimum_pegi = 3)

4. Emit `ratings-submission-manifest` (JSON):
   ```json
   {
     "game_id": "<id>",
     "build_version": "<version>",
     "iarc_questionnaire_version": "<ver>",
     "manifest_timestamp": "<ISO-8601>",
     "answers": [
       {"question_id": "<qid>", "answer": true|false|"REQUIRES_HUMAN_ANSWER", "source_field": "<field>", "advisory_note": "<optional>"}
     ],
     "pegi_2026_predicted_minimum_age": 3|7|12|16|18,
     "pegi_2026_rating_triggers": ["<list of triggered rules>"],
     "human_answer_required_count": N,
     "status": "auto_filled_partial"
   }
   ```

5. If `nft_blockchain: true`: add a compliance flag in the manifest:
   `"compliance_flags": ["NFT_PEGI18_OVERRIDE: DI-011 — NFT triggers PEGI 18 minimum"]`

## Postconditions

- `ratings-submission-manifest` exists at `.factory/artifacts/compliance/<game_id>/
  ratings-submission-manifest-<build_version>.json`.
- Every objective question has a `true`/`false` answer with a `source_field` trace.
- Every content-intensity question has `answer: "REQUIRES_HUMAN_ANSWER"`.
- `pegi_2026_predicted_minimum_age` is computed and reflects all applicable rule triggers.
- No content-intensity question is answered as `true`/`false` by the factory.

## Invariants

- INV-1: The factory answers ONLY objective questions. Content-intensity judgment is always
  `REQUIRES_HUMAN_ANSWER` — no content classifier output may substitute for this.
- INV-2 (DI-011): `nft_blockchain: true` always generates a PEGI 18 override and a
  `compliance_flags` entry. It is never silently ignored.
- INV-3: The questionnaire version is recorded in the manifest; questionnaire schema changes
  require a new manifest generation run.
- INV-4: The `ratings-submission-manifest` is an input to the human-gated submission step
  (BC-10.06.001); it does not itself submit to IARC or any storefront.

## Edge Cases

| EC-ID | Scenario | Expected Result |
|-------|----------|----------------|
| EC-001 | `game-metadata-spec` declares `nft_blockchain: false` but `content_descriptors` includes `NFT_MECHANIC` tag | Inconsistency flagged: `compliance_flags: ["METADATA_INCONSISTENCY: nft_blockchain=false but content_descriptors includes NFT_MECHANIC — human review required"]`; `nft_blockchain` treated as `true` conservatively |
| EC-002 | `user_to_user_communication: true` and `has_block_report_tools: true` | `unrestricted_internet_communications: false`; PEGI 18 unrestricted-comms rule NOT triggered |
| EC-003 | `user_to_user_communication: true` and `has_block_report_tools` not declared | Treated conservatively as `has_block_report_tools: false`; PEGI 18 unrestricted-comms rule triggered; `compliance_flags: ["CONSERVATIVE_ASSUMPTION: has_block_report_tools not declared, treated as false"]` |
| EC-004 | All monetization features absent (solo offline game) | All IAP/gacha/NFT answers `false`; `pegi_2026_predicted_minimum_age: 3`; `human_answer_required_count: N` for content questions |
| EC-005 | Both `random_paid_items: true` AND `nft_blockchain: true` | NFT override wins (PEGI 18); `pegi_2026_rating_triggers: ["random_paid_items_pegi16", "nft_blockchain_pegi18_override"]` |
| EC-006 | Questionnaire version in config not recognized | Error `E-COMP-001`; manifest not emitted |

|-------------------|-------------------------------------------|---------------|
| All features off | 3 | none |

| `time_limited_offers: true` | 12 | `time_limited_offers_pegi12` |
| `random_paid_items: true`, `nft_blockchain: true` | 18 | both triggers; NFT wins |

## Verification Properties

- VP-COMP-001: No content-intensity IARC question is answered with `true` or `false` by the factory.
- VP-COMP-002: `pegi_2026_predicted_minimum_age` is always ≥ 18 when `nft_blockchain: true`.
- VP-COMP-003: Every answered question in the manifest has a `source_field` trace to a
  `game-metadata-spec` field.
