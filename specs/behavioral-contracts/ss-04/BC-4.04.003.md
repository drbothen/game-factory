# BC-4.04.003: A Generated 2D Image Passes the Quality Gate When Resolution Meets Target, Format Matches Declaration, and Provenance Is Complete

## Description

Generated 2D image assets (concept art, textures/materials, UI images, marketing images)
are validated against three structural quality checks: resolution adequacy, output format
correctness, and provenance completeness. This is a lighter-weight gate than BC-4.04.001
because 2D image structural correctness is simpler to check mechanically; aesthetic quality
is NOT gated (consistent with D-006 pure-maximal policy). For materials/textures, an
additional tileability check is applied.

## Preconditions

1. A 2D image asset (PNG, JPG, WEBP) has been generated by a backend adapter.
2. The GenerationRequest specified `output_formats[]` and `budget.texture_res` (minimum
   resolution in pixels on the longest edge).
3. A provenance sidecar has been constructed and attached.

## Behavior

Quality gate check 1 — **Resolution Meets or Exceeds Target:**
- Read the actual image dimensions (width × height).
- If `asset_class: texture_material`: both width and height must be power-of-two
  (e.g., 512, 1024, 2048, 4096) AND ≥ `budget.texture_res` on the shortest edge.
- If `asset_class: concept_2d` or `ui_image`: longest edge must be ≥ `budget.texture_res`.
- If `asset_class: concept_2d` with `use_case_context: marketing`: longest edge must be
  ≥ 1920 pixels (minimum marketing image resolution).
- **Pass:** resolution_check = true.
- **Fail:** E-QG-020.

Quality gate check 2 — **Output Format Matches Declaration:**
- Actual file format (detected by magic bytes, not filename extension) must be in
  `request.output_formats[]`.
- For PNG: no EXIF/XMP metadata containing PII (privacy check; strip-then-ingest if found).
- **Pass:** format_check = true.
- **Fail:** E-QG-021.

Quality gate check 3 — **Tileability (texture_material only):**
- Applies ONLY when `asset_class: texture_material`.
- The texture must be tileable (horizontal and vertical wrap without visible seam).
- Tileability is checked via a wrap-distance metric: the pixel difference at left/right edges
  and top/bottom edges must be ≤ 5% of the mean pixel value (normalized 0-1 scale).
- **Pass:** tile_check = true (or N/A for non-texture asset classes).
- **Fail:** E-QG-022.

Quality gate check 4 — **Provenance Complete:**
- Same rule: sidecar schema-valid, disclosure_class present, copyrightability_assessment present.
- **Pass:** provenance_check = true.
- **Fail:** E-QG-005.

**Aggregation:** Tier-1 fails trigger retry (up to 2) then block. Tier-2/3 fails ingest
with quality_flagged = true. Provenance failure is a hard gate for all tiers.

## Postconditions

- A `quality-gate-report` artifact is produced with all check results.
- `quality_gate_status: pass` assets are available for ingest.
- Format metadata (actual resolution, actual format, tileability score for textures) is
  recorded in the quality-gate-report.

## Invariants

- Aesthetic quality (composition, style consistency, IP scrub) is NOT gated here; it is
  an advisory item only for Tier-3 assets.
- The resolution minimum for marketing assets (1920px longest edge) is a hard check for
  `concept_2d` with `use_case_context: marketing`.
- Provenance failure blocks ALL tiers.

## Edge Cases

| EC-ID | Scenario | Expected Result |
|-------|----------|----------------|
| EC-001 | Texture generated at 512×512 but request budget specifies `texture_res: 1024` | Fail E-QG-020 |
| EC-002 | PNG generated but request specifies `output_formats: ["jpg"]` | Fail E-QG-021 |
| EC-003 | Texture has very slight visible seam at 6% wrap distance | Fail E-QG-022 for tile check (threshold is 5%) |
| EC-004 | Concept art for internal use, 1024×768 (non-power-of-two) | Pass if budget allows; power-of-two rule applies only to `texture_material` class |
| EC-005 | Marketing concept art at 1800px longest edge | Fail E-QG-020 (below 1920 minimum for marketing) |
| EC-006 | Firefly-generated texture: 2048×2048 PNG, full PBR, tileable | Pass all checks; copyrightability_assessment: partial (for indemnified provider with human_modifications_log empty) |
| EC-007 | PNG contains EXIF metadata with GPS coordinates | Format check warns; EXIF is stripped before ingest; not a fail condition |

## Verification Properties

- **VP-4.04.003-a:** `∀ Tier-1 2D asset a ∈ asset_store: a.quality_gate_status = "pass"`
- **VP-4.04.003-b:** `∀ texture_material asset a ∈ asset_store with quality_gate_status = "pass": a.dimensions.width = power_of_two ∧ a.dimensions.height = power_of_two`
- **VP-4.04.003-c:** `∀ 2D asset a: a.quality_gate_status = "pass" → a.sidecar.disclosure_class ∈ valid_disclosure_classes`
