# BC-15.07.001: Remote Config — Fetch, Remote-Config-Contract Binding, and Stale-Data Handling

## Description

The online-services adapter must support remote configuration fetching via
`online.remoteConfig.fetch`. The fetch returns key-value pairs for the declared
`namespace`. When the adapter manifest declares a `contract_ref` for `remote_config`,
the returned values must be validated against the referenced remote-config-contract
document before being used by downstream agents. A stale fetch (backend unreachable,
using cached values beyond their TTL) returns `E-OSVC-006` (`RemoteConfigStale`).
A partial fidelity declaration indicates that A/B testing or full feature-flag set
may not be available.

## Preconditions

1. The online-services adapter manifest is valid (BC-15.01.001 passed).
2. `capabilities.remote_config.fidelity` is `full` or `partial`.
3. A valid session token has been obtained (where adapter requires auth for config fetch).
4. The `namespace` is a configured namespace in the BaaS backend.

## Postconditions

1. **PASS — fetch:** `online.remoteConfig.fetch` with `{playerId?, namespace}` returns
   `{values: {<key>: <value>}}`. The `values` object is non-null (may be empty `{}` if
   no keys are configured for the namespace, but it is not absent).
2. **PASS — contract-bound fetch:** When `capabilities.remote_config.contract_ref` is
   declared, the returned values must pass schema validation against the referenced
   remote-config-contract document. Any value that fails contract schema validation
   causes the entire fetch result to be rejected. Error: `E-OSVC-007`
   (`RemoteConfigContractViolation`). Message: `remote_config.fetch: namespace '<ns>'
   key '<key>' value '<v>' fails contract '<contract_ref>' schema at '<path>'`.
3. **FAIL — stale config:** Backend unreachable and cached config TTL has expired. Error:
   `E-OSVC-006` (`RemoteConfigStale`). Message: `remote_config.fetch: namespace '<ns>'
   cache expired at '<expiry>'; backend unreachable; returning stale error`.
   Note: if cached config is within TTL, the adapter MAY return cached values without
   error (degraded mode), logging the cache hit.
4. **FAIL — namespace not found:** `namespace` is not configured in the backend. Error:
   `E-OSVC-008` (`RemoteConfigNamespaceNotFound`).
5. **FAIL — backend unreachable, no cache:** Error: `E-OSVC-001` (`BackendUnreachable`).

## Invariants

1. Config fetch results are never fabricated by the adapter. The adapter returns backend
   values or a documented error — it does not synthesize config values.
2. When `contract_ref` is declared, validation is mandatory and fail-closed: a single
   contract violation rejects the entire namespace fetch.
3. Partial fidelity indicates the adapter may return a subset of keys or may not support
   A/B experiment variants. The subset must still be contract-validated if `contract_ref`
   is declared.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Namespace exists but has no keys configured | `{values: {}}` — empty but valid |
| EC-002 | Backend unreachable; cache within TTL | Cached values returned; cache-hit logged; no error |
| EC-003 | Backend unreachable; cache expired | E-OSVC-006 RemoteConfigStale |
| EC-004 | Returned value fails contract schema | E-OSVC-007 RemoteConfigContractViolation; entire fetch rejected |
| EC-005 | `remote_config.fidelity: none` | E-EAP-002 CapabilityUnsupported |
| EC-006 | `contract_ref` declared but contract document not found | E-OSVC-007 with message indicating contract document unresolvable |
