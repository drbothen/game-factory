# BC-13.04.001: Store Page Asset Conformance

## Description

When the marketing lane is active, the factory generates store page assets for each
declared target platform and validates them against the platform's published asset
specifications. Asset dimensions, file formats, file sizes, and text-field character
limits are machine-checkable against the platform specs (all primary-source verified
against partner.steamgames.com, developer.apple.com, support.google.com as of June 2026).
Console and Xbox store specs are partially NDA-gated; those targets are declared as
`human-gated` in the conformance result. The factory never generates review scores,
awards text, or discount text in capsule images (Steam rules prohibit this).

## Preconditions

1. The marketing lane is active and includes `store_page: true` in the genre profile.
2. `marketing_config.platforms` declares one or more of: `steam`, `apple_app_store`,
   `google_play`, `xbox` (xbox is partially human-gated).
3. Game key art, logo, and screenshot assets have been generated by the asset pipeline
   (CAP-004) with provenance sidecars.
4. All generated assets include a valid `disclosure_class` in their provenance sidecar
   (DI-003).

## Postconditions

1. For each declared platform, a `store-page-spec` artifact is generated containing:
   - Platform asset requirements (from the specification table below).
   - The generated asset file list with actual dimensions, format, and file size.
   - Conformance result per asset: `pass`, `fail`, or `human_gated`.
2. Assets that fail dimension or format requirements are flagged with `E-MKT-001`
   (asset spec violation); the specific violation is described (expected vs actual).
3. The AI disclosure requirement is enforced: if any asset has `disclosure_class: ai_generated`,
   the Steam store page includes the AI disclosure flag as required by Steam's AI content
   policy (Steamworks AI disclosure, Jan 2026).
4. Capsule images do not contain review scores, award text, or discount text.

## Platform Asset Specifications (machine-checkable, primary-source verified)

### Steam (verified against partner.steamgames.com, June 2026)

| Asset type | Required dimensions | Format | Notes |
|-----------|--------------------|---------|----|
| Header capsule | 460 × 215 px | JPG / PNG | — |
| Small capsule | 231 × 87 px | JPG / PNG | — |
| Main capsule | 616 × 353 px | JPG / PNG | — |
| Vertical capsule | 374 × 448 px | JPG / PNG | — |
| Screenshots | ≥ 5, 1280 × 720 px min | JPG / PNG | Gameplay or game content only |
| Trailer | 1920 × 1080 px | .mov / .wmv / .mp4 | H.264/AAC, 30 or 60fps, ≥ 5000 Kbps |
| Background | 1438 × 810 px | JPG / PNG | Optional |

**Steam capsule text rules:** no review scores, award logos, or discount text in capsule images.

### Apple App Store (verified against developer.apple.com, June 2026)

| Asset type | Required dimensions | Format | Notes |
|-----------|--------------------|---------|----|
| App name | ≤ 30 characters | text | — |
| Subtitle | ≤ 30 characters | text | — |
| Keywords | ≤ 100 characters | text | — |
| Screenshots | ≤ 10 per device | PNG / JPG | Exact px per device (iPhone 6.9" = 1320×2868; see spec) |
| App Previews | ≤ 3, ≤ 30 seconds | MP4 | — |
| App Icon | 1024 × 1024 px | PNG | No alpha channel |

### Google Play (verified against support.google.com, June 2026)

| Asset type | Required dimensions | Format | Notes |
|-----------|--------------------|---------|----|
| App icon | 512 × 512 px | PNG | ≤ 1024 KB |
| Feature graphic | 1024 × 500 px | JPG / PNG | — |
| Screenshots | ≥ 2 per device type | PNG / JPG | — |

### Xbox / Microsoft Store (partially NDA-gated)

| Asset type | Required dimensions | Format | Notes |
|-----------|--------------------|---------|----|
| Hero art | 1920 × 1080 px (or 3840 × 2160) | JPG | Public spec |
| Trailer thumbnail | 1920 × 1080 px | JPG | Public spec |
| Screenshots | ≤ 30 | PNG / JPG | Public spec |
| Box art (9:16 poster art) | NDA-gated | — | `human_gated: true` |

## Invariants

1. The factory generates only assets whose specifications are publicly verified — it
   never invents spec requirements.
2. NDA-gated asset types (Xbox 9:16 poster art, console store assets) are declared
   `human_gated` and appear as checklist tasks, not generated artifacts.
3. Generated capsule images never include review scores, award text, or promotional
   text about discounts (Steam rules; verified against partner.steamgames.com).
4. AI disclosure is non-optional: if any store asset is `disclosure_class: ai_generated`,
   the platform's AI disclosure mechanism is activated.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Game has no screenshots yet at marketing lane activation | `E-MKT-002` (insufficient screenshots: Steam requires ≥5); human task surfaced to supply screenshots |
| EC-002 | App name exceeds 30 characters on Apple App Store | `E-MKT-001`; truncation suggestion emitted; human reviews |
| EC-003 | Asset has `disclosure_class: ai_generated` on Steam | AI disclosure flag automatically set in store page config; no manual step required |
| EC-004 | Screenshot generated with wrong aspect ratio (e.g., 4:3 instead of 16:9) | `E-MKT-001` (dimension violation); asset regeneration triggered with corrected parameters |
| EC-005 | All assets conform for Steam; Xbox 9:16 poster art required | Steam: `conformance_status: pass`; Xbox: `conformance_status: human_gated` + checklist task emitted |
