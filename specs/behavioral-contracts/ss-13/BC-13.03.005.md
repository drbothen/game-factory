# BC-13.03.005: Moderation Pipeline Contract — UGC/Chat CSAM Reporting and Fail-Closed Enforcement

## Description

Any game with UGC or chat features enabled must declare and wire a conformant
moderation pipeline before D-SEC passes. The pipeline must have a declared provider,
a CSAM detection method, and a configured NCMEC CyberTipline report path (18 U.S.C.
§2258A). The moderation pipeline is fail-closed: if the pipeline is unavailable, UGC
is BLOCKED — not silently accepted. Any CSAM-suspect content triggers a human review
queue (DI-006) and is never auto-deleted without a human-reviewed evidence record.

## Preconditions

1. The genre profile declares `ugc_enabled: true` OR `chat_enabled: true` for the
   target game.
2. A `moderation-pipeline-manifest` document is present in the game artifact set,
   declaring at minimum:
   - `provider`: the moderation service provider identifier (non-empty string).
   - `csam_detection_method`: the technical detection approach used.
   - `ncmec_report_path`: the configured NCMEC CyberTipline endpoint or integration.
3. The factory output bundle is staged for D-SEC gate evaluation.

## Postconditions

1. **PC1 — Provider declared non-empty:** `moderation-pipeline-manifest.provider` is
   present and non-empty. An absent or empty-string provider causes `E-TMOD-001`
   and blocks D-SEC.
2. **PC2 — CSAM detection method declared:** `csam_detection_method` is one of:
   `PhotoDNA`, `C2PA scan`, `hash-match`. Any other value (or absence) causes
   `E-TMOD-001`.
3. **PC3 — NCMEC report path non-null:** `ncmec_report_path` is declared and non-null.
   The NCMEC CyberTipline integration must be configured. Absence causes `E-TMOD-002`.
4. **PC4 — Fail-closed:** If the moderation pipeline is declared unavailable or
   degraded at runtime, UGC ingestion is BLOCKED. Silent acceptance of UGC when the
   pipeline is unavailable is a defect. Any degraded pipeline state must be declared
   explicitly in the manifest's `degraded_behavior` field; an undeclared degraded
   state is treated as `block_ugc` (most restrictive default). A `degraded_behavior:
   pass_through` (fail-open) value causes `E-TMOD-003` and blocks D-SEC.
5. **PC5 — Human review queue for CSAM-suspect:** When a CSAM-suspect signal is
   raised, the factory surfaces a human review task (DI-006) with the suspect
   content ID and detection evidence. The content is quarantined pending human
   review. Auto-deletion without a human-reviewed evidence record is a hook-
   detectable defect.

## Invariants

1. **INV-1:** No game with `ugc_enabled: true` or `chat_enabled: true` may have a
   deployed factory output bundle without a declared and structurally valid
   `moderation-pipeline-manifest`. Absence of the manifest for an in-scope game
   is a D-SEC BLOCKED condition — not a degraded state.
2. **INV-2:** Moderation pipeline absence for in-scope games equals D-SEC BLOCKED.
   There is no graceful degradation path for a missing moderation pipeline on
   UGC/chat-enabled games.
3. **INV-3:** Human review tasks for CSAM-suspect content are governed by DI-006 —
   they are surfaced, checklisted, and must not be suppressed or silently dropped.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Genre profile has `ugc_enabled: false` AND `chat_enabled: false` | Moderation pipeline manifest is not required; this BC is INAPPLICABLE for the game |
| EC-002 | `moderation-pipeline-manifest` present but `provider` is empty string | `E-TMOD-001` emitted; D-SEC gate BLOCKED |
| EC-003 | `csam_detection_method` is `manual-review-only` (not in allowed set) | `E-TMOD-001` emitted; D-SEC gate BLOCKED; must use one of {PhotoDNA, C2PA scan, hash-match} |
| EC-004 | `ncmec_report_path` is `null` or absent | `E-TMOD-002` emitted; D-SEC gate BLOCKED |
| EC-005 | `degraded_behavior: pass_through` declared in manifest | `E-TMOD-003` emitted; D-SEC gate BLOCKED — fail-open moderation is not a valid configuration |
| EC-006 | `degraded_behavior` field absent; pipeline is unavailable at runtime | Treated as `block_ugc` by default; UGC blocked; no E-TMOD error (default is correct behavior) |
| EC-007 | CSAM-suspect flag raised by PhotoDNA; factory attempts to auto-delete content | BLOCKED: factory must quarantine and surface human review task (DI-006); auto-deletion without human-reviewed evidence record is a defect |
| EC-008 | Game has `chat_enabled: true` only (no UGC); moderation manifest absent | `E-TMOD-001` emitted; D-SEC gate BLOCKED — chat-only games are in scope for this BC |
