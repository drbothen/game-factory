# BC-13.01.001: Genre Profile Schema Validation

## Description

A genre profile document is the machine-readable configuration that controls which optional
production lanes are active for a given game. Before any lane may be activated, the genre
profile must pass structural schema validation — all required fields present with correct
types, all enum values drawn from the declared set, all lane configuration objects
internally consistent. An invalid genre profile must block lane activation entirely and
surface a typed error, never silently activating with defaults.

## Preconditions

1. A genre profile document exists at the canonical path for the game spec.
2. The factory schema registry contains the `genre-profile-schema` at version 1.0 or later.
3. The validation engine is invoked as part of the lane-activation gate (before any lane
   artifact generation begins).

## Postconditions

1. **Valid profile:** schema validation returns `valid: true`; lane-activation proceeds per
   the profile's declared lane flags; each activated lane receives its typed config object.
2. **Invalid profile:** schema validation returns `valid: false` with a structured error
   list (field path, violation type, expected vs. actual); no lane is activated; no
   lane-specific artifacts are generated; the error is surfaced as `E-GLG-001`.
3. The validation result (pass or fail) is recorded in the pipeline artifact log with the
   genre profile's input hash.

## Invariants

1. Schema validation is deterministic: the same genre profile document always produces the
   same pass/fail result against the same schema version.
2. Schema validation never partially activates lanes — it is an all-or-nothing gate: either
   the entire profile is valid and lanes activate per declarations, or the entire profile is
   rejected and no lanes activate.
3. The schema version used for validation is recorded in the pipeline artifact log alongside
   the profile input hash (enabling drift detection when the schema evolves).

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Genre profile is an empty document / zero-byte file | Validation fails with `E-GLG-001`; error message indicates "empty or missing genre profile"; no lanes activated |
| EC-002 | Genre profile declares a lane name not in the schema enum (e.g., a misspelled `espots_enabled`) | Validation fails with `E-GLG-001`; error message identifies the unknown field; no lanes activated |
| EC-003 | Genre profile activates a lane but omits the lane's required config object | Validation fails with `E-GLG-001`; error identifies missing required lane config; no lanes activated |
| EC-004 | Genre profile sets all lane flags to `false` (all lanes off) | Validation passes; zero lane-specific artifacts are generated; core pipeline proceeds unaffected |
| EC-005 | Genre profile schema has a newer version than the factory's current registry | Validation fails with `E-GLG-002` (schema version not supported); human-readable upgrade message included |
| EC-006 | Genre profile contains extra unknown keys beyond the schema | Validation fails with `E-GLG-001` (strict mode); no lanes activated. NOTE: schema must be strict (no unknown fields) to prevent silent misconfiguration |
