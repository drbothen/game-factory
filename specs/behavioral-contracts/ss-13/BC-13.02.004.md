# BC-13.02.004: Spectator Spec — Observer Data Layer

## Description

When the esports lane declares spectator support, the factory generates a `spectator-spec`
artifact defining the machine-verifiable data layer for the observer feed: broadcast/
observer delay bound, fog-of-war / interest-management visibility correctness, and the
deterministic auto-director camera-selection function. These are the structural, data-
correct properties of the spectator system. The production layer — casting quality,
director's artistic choices, overlay graphic design, live booth operations — is explicitly
human-owned and out of autonomous factory scope.

## Preconditions

1. The esports lane is active (`esports_enabled: true`) in the validated genre profile.
2. `esports_config.spectator` is present and declares at minimum `observer_delay_seconds`
   and `fog_of_war_mode` (one of `none`, `team_only`, `full_fog`).
3. The game's server-authority model is established (anti-cheat / trust-safety vector
   invariants are in scope for the underlying interest-management system).

## Postconditions

1. A `spectator-spec` artifact is generated containing:
   - `observer_delay_seconds`: N ≥ 0; broadcast feed is delayed ≥ N seconds vs
     authoritative server time.
   - `fog_of_war`: visibility set definition — which game state each observer class may
     see, consistent with `fog_of_war_mode`.
   - `auto_director`: if present, declares the camera-selection function as deterministic
     given world state; includes the state input schema and camera selection output type.
   - `hud_stat_schema`: if present, defines the data schema for HUD overlay statistics;
     declares the correctness invariant "HUD stats match authoritative sim state."
2. The observer delay property is machine-verifiable as: `observed_feed_timestamp ≤
   authoritative_timestamp − observer_delay_seconds`.
3. The fog-of-war correctness property is machine-verifiable as: `observer_visibility_set
   == authorized_visibility_set(observer_class, fog_mode)`.
4. The auto-director camera-selection function is machine-verifiable as: given the same
   world state, `director_fn(state) == director_fn(state)` (deterministic).
5. All data-layer properties are verifiable without a physical headset or live audience.

## Invariants

1. Observer delay ≥ 0; the spec may NOT declare a negative delay (observers seeing the
   future is not a valid configuration).
2. The fog-of-war visibility set is always a subset of the full authoritative state — an
   observer can never see more than the server authorizes.
3. The auto-director function, if present, is a pure function of world state: no side
   effects, no I/O, deterministic output.
4. HUD stats declared in `hud_stat_schema` must derive from authoritative simulation
   state — no client-side extrapolation may diverge from the authoritative feed.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Observer delay = 0 (real-time observer, e.g., admin/debug) | Artifact generated with `observer_delay_seconds: 0`; noted as appropriate only for admin/debug use in the artifact commentary |
| EC-002 | Fog-of-war mode `full_fog`: observer sees only their authorized team's state | Visibility set contains only friendly units/positions; enemy positions absent from observer feed |
| EC-003 | Auto-director receives a world state with no active combat (quiet period) | Director returns a valid camera selection (e.g., economy overview or objective focus); never returns null |
| EC-004 | HUD stat schema includes a statistic derived from the full authoritative state but with a T2/T3 engine adapter (non-bitwise) | Stat correctness is defined within the engine adapter's tolerance window; `correctness_mode` set to `tolerance` in the artifact |
| EC-005 | Spectator feed is requested before the game has started (pre-match lobby) | Observer delay invariant still applies; pre-match lobby feed is the authoritative pre-match state delayed by N seconds |

## Canonical Test Vectors

| Input | Expected Output | Category |
|-------|----------------|----------|
| `observer_delay_seconds: 120`, live feed at T=300s | Observer sees feed at T ≤ 180s; `observed_timestamp ≤ 180` | happy-path |
| `fog_of_war_mode: team_only`, observer on team A | Visibility set contains only team A positions and team A-visible enemy positions; enemy positions outside team A fog-of-war absent | happy-path |
| Auto-director: world state with 3 simultaneous fight clusters | Director function deterministically returns one camera; same state → same camera on re-invocation | happy-path |
| `observer_delay_seconds: -10` | Schema validation fails (E-GLG-001): negative delay not permitted | error |
| HUD stat schema references a field not present in the sim state schema | Schema validation fails (E-GLG-001): stat field undefined | error |
