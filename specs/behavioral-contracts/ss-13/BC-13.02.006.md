# BC-13.02.006: Anti-Cheat Integration Adapter — Allowed-Provider Enforcement and Kernel-Anomaly Rejection

## Description

Competitive multiplayer games and games with an active esports lane must declare a
conformant anti-cheat provider before D-SEC passes. The declared provider must be in
the factory-allowed set `{eac, eos, battleye}` (case-insensitive) per ADR-0008. Any
kernel-anomaly provider (specifically Riot Vanguard and its variants: `vanguard`,
`riot-vanguard`, `vgk`, `riot_vanguard`) is unconditionally rejected with
`E-ANTICH-002` and blocks scaffolding generation. The factory generates
wrap-only integration scaffolding; it never authors the provider service binary.
Generated scaffolding must pass the BC-1.15.002 lint check (no ring-0 driver artifacts).

## Preconditions

1. The genre profile declares `competitive_multiplayer: true` OR the esports lane is
   active (`esports_enabled: true`).
2. An `anti_cheat_config` document is present in the game artifact set, declaring at
   minimum:
   - `provider`: the anti-cheat provider identifier (non-empty string).
   - `integration_mode`: must be `wrap-only`.
3. The factory output bundle is staged for D-SEC gate evaluation and BC-1.15.002 lint.

## Postconditions

1. **PC1 — Provider declared non-empty:** `anti_cheat_config.provider` is present and
   non-empty. Absence causes `E-ANTICH-003`.
2. **PC2 — Provider in allowed set:** `provider` value (lowercased) is one of:
   `eac`, `eos`, `battleye`. Any other value causes `E-ANTICH-001`.
3. **PC3 — Kernel-anomaly provider unconditionally rejected:** If `provider` resolves
   (case-insensitive, after normalizing hyphens and underscores) to any of:
   `vanguard`, `riot-vanguard`, `vgk`, `riot_vanguard` — the factory emits
   `E-ANTICH-002` and blocks all scaffolding generation. This rejection is not
   overridable by any flag, config value, or agent instruction. Riot Vanguard is
   not licensable (DI-010) and uses a kernel-anomaly architecture incompatible
   with factory scope.
4. **PC4 — Generated scaffolding passes BC-1.15.002 lint:** All factory-generated
   integration scaffolding passes the kernel-mode pattern scan defined in
   BC-1.15.002. No ring-0 driver artifacts, kernel-mode entry points, or kernel
   binary blobs appear in the output bundle.
5. **PC5 — Wrap-only mode enforced:** `integration_mode` must be `wrap-only`. The
   factory generates only user-mode SDK wrapper scaffolding that calls the
   provider's user-mode API surface. The factory never authors the provider service
   binary or kernel driver.

## Invariants

1. **INV-1:** A competitive multiplayer or esports-enabled game without a declared
   `anti_cheat_config.provider` is a conformance failure — not a degraded state.
   D-SEC is BLOCKED if the provider is absent for an in-scope game.
2. **INV-2:** Riot Vanguard (and all `vgk`/`riot-vanguard`/`riot_vanguard` aliases)
   is NEVER a valid provider value. This constraint is not overridable by any flag,
   config, runtime override, or agent instruction. It is a factory-level invariant
   enforcing DI-010 (Kernel Anti-Cheat Is Never Autonomously Authored) and
   ADR-0008 (kernel-anomaly provider rejection policy).
3. **INV-3:** The factory always operates in wrap-only mode for anti-cheat
   integration; the factory never authors or ships the provider's binary.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | `anti_cheat_config.provider: "eac"` (Easy Anti-Cheat) | PASS: provider in allowed set; wrap-only EAC SDK scaffolding generated |
| EC-002 | `anti_cheat_config.provider: "EOS"` (case variant of EOS) | PASS: lowercased "eos" is in allowed set |
| EC-003 | `anti_cheat_config.provider: "BattlEye"` (case variant) | PASS: lowercased "battleye" is in allowed set |
| EC-004 | `anti_cheat_config.provider: "riot-vanguard"` | `E-ANTICH-002` emitted; scaffolding generation BLOCKED; rejection unconditional |
| EC-005 | `anti_cheat_config.provider: "vgk"` (vgk.sys alias) | `E-ANTICH-002` emitted; scaffolding generation BLOCKED; vgk is a Riot Vanguard alias |
| EC-006 | `anti_cheat_config.provider: "riot_vanguard"` (underscore variant) | `E-ANTICH-002` emitted; scaffolding generation BLOCKED |
| EC-007 | `anti_cheat_config.provider: "custom-ac"` (custom provider not in allowed set) | `E-ANTICH-001` emitted; D-SEC BLOCKED — only {eac, eos, battleye} are valid |
| EC-008 | `anti_cheat_config` absent for `competitive_multiplayer: true` game | `E-ANTICH-003` emitted; D-SEC BLOCKED — provider declaration is required |
| EC-009 | `integration_mode: "full-service"` declared | BLOCKED: only `wrap-only` is a valid integration mode; schema validation fails |
| EC-010 | Genre profile: `competitive_multiplayer: false`; esports lane inactive | Anti-cheat config not required; this BC is INAPPLICABLE for the game |
| EC-011 | PRD or config requests kernel-level Vanguard despite `anti_cheat_config` | Factory rejects with `E-ANTICH-002`; this is not overridable by instruction |
