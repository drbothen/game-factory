# BC-11.03.001: Forbidden Dark Pattern — Loot Box Without Odds Disclosure (DP-005)

## Description

Defines the machine-checkable enforcement of dark pattern DP-005: any game
config that declares a gacha or loot-box mechanic (via `gacha-spec` artifact)
MUST have a `published_odds` field that is non-null, non-empty, and covers
every rarity tier in the spec's declared item pools. This obligation is grounded
in verified regulatory requirements (Apple App Store Dec 2017; Google Play May
30 2019; ESRB "In-Game Purchases (Includes Random Items)" Apr 2020; PEGI 16
minimum for paid random items effective Jun 2026). Absence of odds disclosure
on a gacha mechanic is both a dark pattern and a regulatory non-compliance.

## Preconditions

1. A `gacha-spec` artifact exists for this game_id.
2. The `monetization-ethics-contract` is structurally valid (BC-11.01.001 PASS).
3. `gacha-spec.paid_pulls_enabled == true` (i.e., the mechanic requires real
   money or premium currency purchasable with real money).

## Postconditions

1. **COMPLIANT:** `gacha-spec.published_odds` is present, non-empty, and
   contains a probability entry for every rarity tier declared in
   `gacha-spec.item_pools`. All declared pull probabilities sum to 1.0
   (±0.0001 floating-point tolerance). Pity mechanism (if present) is
   described in `published_odds.pity_description`.
2. **VIOLATION (missing odds):** `gacha-spec.published_odds` is null or
   missing. Error: **E-ETH-010** (`error.data.reason: GACHA_ODDS_DISCLOSURE_MISSING`).
   Pipeline BLOCKED. This is both a dark-pattern violation (DP-005) and a
   regulatory non-compliance flag for Apple, Google, ESRB, and PEGI rating targets.
3. **VIOLATION (incomplete odds):** `published_odds` is present but does not
   cover all rarity tiers in `item_pools`. Error: **E-ETH-010**
   (`error.data.reason: GACHA_ODDS_DISCLOSURE_INCOMPLETE`) with the list of
   uncovered tiers.
4. **VIOLATION (probability sum):** Declared probabilities do not sum to 1.0
   within tolerance. Error: **E-ETH-010**
   (`error.data.reason: GACHA_ODDS_PROBABILITY_INCONSISTENT`) with the measured sum.
5. **FREE-PULLS ONLY:** `paid_pulls_enabled == false` (gacha is free-only,
   e.g., earned through gameplay). DP-005 does not apply; this check is a
   PASS-EXEMPT. However, a warning is emitted recommending odds disclosure
   even for free gacha to maintain transparency.

## Invariants

1. Odds disclosure is mandatory for ANY paid gacha mechanic regardless of which
   `declared_mechanics_allow_list` in the ethics contract includes it. The
   obligation is unconditional once `paid_pulls_enabled == true`.
2. The `published_odds` field must match the ACTUAL pull probabilities
   specified in the gacha simulation config. A disclosure that does not match
   the implementation is a fraudulent disclosure, not a compliant one.
   BC-11.04.001 verifies pity correctness; this BC verifies disclosure presence.
3. Pity mechanic descriptions in `published_odds.pity_description` are required
   when a pity mechanism is declared in the spec. A pity mechanic without
   disclosure is as much a violation as missing base rates.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | `gacha-spec` present but ethics contract has `gacha_permitted: false` | The `gacha-spec` itself is a policy violation per BC-11.01.001. DP-005 check fires secondarily. The primary error is the mechanic-not-permitted error. |
| EC-002 | Declared probabilities sum to 0.9999 (floating-point rounding) | PASS: within the ±0.0001 tolerance. |
| EC-003 | Probabilities sum to 0.95 (5% gap — likely a missing tier) | FAIL: E-ETH-010 (`GACHA_ODDS_PROBABILITY_INCONSISTENT`). 5% gap is outside tolerance; likely a missing item tier. |
| EC-004 | "Soft pity" mechanic (probability increases at pull 74+) without disclosure | FAIL: E-ETH-010 (`GACHA_ODDS_DISCLOSURE_INCOMPLETE`). Soft pity is a meaningful change to the probability distribution that must be disclosed. `pity_description` must describe the ramp. |
| EC-005 | Duplicate item conversion mechanic (e.g., duplicate 5-star → resource shards) | PASS for DP-005 if base pull rates are disclosed. However, if the duplicate conversion affects effective cost-to-target materially, BC-11.04.001 may flag it. |
| EC-006 | Game targets regions where loot boxes are banned or restricted (Belgium: gambling law; China: volume limits) | DP-005 still applies for non-banned regions. Separately, `regional_restrictions` in ethics contract must mark `gacha_off_in_belgium: true`. This BC is not the regional check — that is a separate compliance assertion. |
