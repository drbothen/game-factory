# BC-11.01.001: Ethics Contract Structural Validity

## Description

Defines what makes a `monetization-ethics-contract` structurally valid. A
valid contract must exist for any game whose `business-model-spec` declares
non-premium-only monetization, must contain all mandatory fields (including
an explicit `unconstrained_ltv_maximize: false`), must have a declared
validation method (per DI-012), and must be marked as human-authored. A
structurally invalid or absent contract when monetization is present is
treated as a factory defect, not a warning.

## Preconditions

1. A `GameSpec` has been created and its `monetization_model` field is set.
2. A `business-model-spec` artifact exists and its `archetype` field is
   populated.
3. The factory pipeline has reached the monetization-ethics validation gate
   (i.e., convergence dimension #10 is being evaluated).

## Postconditions

1. **VALID:** The `monetization-ethics-contract` artifact exists, contains
   all mandatory fields (contract_id, game_id, declared_mechanics_allow_list,
   forbidden_patterns, optimization_objective with non-empty constraints,
   disclosure_requirements, pressure_bounds, minor_protection,
   regional_restrictions, adversarial_review_evidence_ref placeholder,
   validation_method, authored_by_human), and `authored_by_human == true`
   and `unconstrained_ltv_maximize == false`.
2. **ABSENT / DEFECT:** `business-model-spec.archetype != "premium"` AND no
   `monetization-ethics-contract` artifact exists. Pipeline build FAILS with
   error `ETHICS_CONTRACT_ABSENT`. This is a factory defect, not a warning.
3. **STRUCTURALLY INVALID:** Contract exists but one or more mandatory fields
   are missing or malformed. Pipeline returns error `ETHICS_CONTRACT_INVALID`
   with a field-level diff listing every missing/malformed field.
4. **PROHIBITED OBJECTIVE:** `optimization_objective.unconstrained_ltv_maximize
   == true` or the field is absent. Pipeline FAILS with error
   `UNCONSTRAINED_LTV_OBJECTIVE_DETECTED`. This is a factory defect.

## Invariants

1. Any game with `monetization_model != "none"` MUST have a structurally valid
   `monetization-ethics-contract`. There is no exception to this rule.
2. The contract must be human-authored (`authored_by_human: true`). The factory
   may scaffold the template, but a human must complete the policy declarations.
   An auto-generated contract without human sign-off is structurally invalid.
3. `unconstrained_ltv_maximize` must be explicitly present and set to `false`.
   Absence is treated as `true` for safety (fail-closed).
4. Every `monetization-ethics-contract` must declare its `validation_method`
   at creation time (per DI-012). A contract without a declared validation
   method is structurally invalid regardless of other fields.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | `business-model-spec.archetype == "premium"` with no IAP, ads, or gacha | Ethics contract is not required; convergence dim-10 is GREEN with a `premium_only_no_monetization_ethics_required` note. If any downstream artifact adds a monetization mechanic, the gate re-triggers. |
| EC-002 | Contract present but `authored_by_human` field is missing (older schema) | Treated as `authored_by_human: false`; contract is structurally invalid; pipeline returns `ETHICS_CONTRACT_INVALID` with field `authored_by_human` listed as missing. |
| EC-003 | Contract present with `unconstrained_ltv_maximize` field absent | Fail-closed: treated as `true`; pipeline FAILS with `UNCONSTRAINED_LTV_OBJECTIVE_DETECTED`. |
| EC-004 | Contract present with `optimization_objective.constraints` is an empty array | Structurally invalid: empty constraints array is treated as unconstrained optimization. Pipeline returns `ETHICS_CONTRACT_INVALID`. |
| EC-005 | Multiple `monetization-ethics-contract` artifacts for the same `game_id` | The most recent by `timestamp` field is used. If two have the same timestamp, pipeline returns `ETHICS_CONTRACT_AMBIGUOUS` and blocks until resolved. |
| EC-006 | `declared_mechanics_allow_list` is empty | Structurally invalid. An empty allow-list means no mechanics are permitted — this is a valid strict policy, BUT the factory requires the list to be explicitly populated (even if only `["none"]`). Empty array is treated as a schema error. |
| EC-007 | Game starts as premium (`monetization_model: premium`) and mid-production a DLC is added changing it to hybrid | Ethics contract gate re-fires on `business-model-spec` change. Existing premium-only exemption is revoked. New contract required before monetization-mechanics artifacts are accepted. |
