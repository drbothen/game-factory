# BC-11.04.002: Spend-Concentration Guardrail (Gini Coefficient Bound)

## Description

Defines the machine-checkable assertion that the simulated spend distribution
across player archetypes does not exceed the Gini coefficient threshold
declared in the `monetization-ethics-contract`. The Gini coefficient measures
spend concentration: a value of 0.0 = perfectly equal spend distribution; a
value approaching 1.0 = one player bears essentially all spend. This BC
prevents the factory from generating a monetization design that structurally
depends on "whale economics" (a small number of extreme spenders driving all
revenue) beyond the threshold the ethics contract has explicitly declared
acceptable. The measurement is purely over simulated archetype distributions,
not live player data. It is the ethics contract's guardrail against convergent
whale-exploitation, grounded in monetization-business-model.md §5.2.

## Preconditions

1. `monetization-ethics-contract.constraints` contains a
   `max_spend_concentration_gini` constraint with a declared threshold in
   range [0.0, 1.0].
2. `sink-faucet-model` declares at least 3 distinct player archetypes with
   different spend propensities (e.g., non_payer, casual_spender, whale).
3. The economy simulation has run at minimum 10,000 simulated player-years
   per archetype to produce a spend distribution.
4. The simulation produces a `spend_distribution` output: list of
   (archetype, total_spend_usd) pairs, suitable for Gini calculation.

## Postconditions

1. **PASS:** The Gini coefficient computed over the simulated spend
   distribution is <= `max_spend_concentration_gini`. The specific
   Gini value is recorded in the convergence report for monitoring.
2. **FAIL:** Computed Gini > `max_spend_concentration_gini`. Error:
   `SPEND_CONCENTRATION_EXCEEDS_ETHICS_BOUND`: computed_gini, threshold,
   archetype breakdown showing which archetypes drive the concentration.
3. **CONSTRAINT ABSENT:** No `max_spend_concentration_gini` constraint in the
   ethics contract. Warning: `SPEND_CONCENTRATION_GUARDRAIL_NOT_DECLARED`.
   The factory cannot evaluate this without a declared bound. Adversarial
   review must ensure this is intentional policy (e.g., premium games with no
   variable spend have trivially-0 Gini and the check is vacuous).
4. **SIMULATION INSUFFICIENT:** Fewer than 3 archetype types declared, or
   simulation run insufficient. Warning: `SPEND_CONCENTRATION_INSUFFICIENT_SIMULATION`.
   Cannot compute Gini reliably; adversarial review must flag.

## Invariants

1. The Gini calculation uses simulated spend distributions over declared
   player archetypes. It does NOT require live player data and NEVER uses
   actual player spend records. The simulation runs over the factory's
   declared archetype distributions.
2. A high Gini coefficient is not automatically forbidden — the ethics contract
   explicitly declares the acceptable threshold. The factory measures and
   reports; the threshold is human policy. But the factory must ensure the
   declared threshold is not exceeded.
3. The Gini value is a GUARDRAIL metric, not an optimization objective. The
   factory never optimizes to minimize Gini (that could perversely hurt revenue
   without ethical benefit). It only checks that Gini doesn't exceed the declared
   maximum.
4. For premium games with no variable spend, Gini = 0 trivially. The
   `max_spend_concentration_gini` constraint may be absent or set to 1.0
   for premium-only games (every player spends the same fixed amount).

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Premium game; all players pay $30 and nothing else | Gini = 0. PASS trivially. |
| EC-002 | Cosmetics-only F2P; some players buy 1 skin, some buy 50 | Gini computed over spend distribution. If concentrated, may exceed threshold. Ethics contract should declare an appropriate bound for cosmetics-heavy models. |
| EC-003 | Gacha game; whale archetype declared with spend propensity 50× the casual archetype | Gini may be high (0.7+). If ethics contract allows up to 0.80, PASS; if only 0.70, FAIL. |
| EC-004 | Ethics contract declares `max_spend_concentration_gini: 0.95` (very permissive) | PASS as long as Gini <= 0.95. But the adversarial review (A-02) will scrutinize whether this threshold is genuinely constrained or de-facto unconstrained. A threshold ≥ 0.95 is a red flag for the adversary. |
| EC-005 | Simulation produces a bimodal spend distribution (non-payers and whales; no mid-tier) | Gini may be high. The Gini calculation still works correctly on bimodal distributions. |
| EC-006 | `max_spend_concentration_gini` is set to 1.0 (unconstrained) | Warning: `SPEND_CONCENTRATION_GINI_EFFECTIVELY_UNCONSTRAINED`. This is semantically equivalent to no constraint. Adversarial review A-02 must explicitly sign off on a 1.0 threshold. |
