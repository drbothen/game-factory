# BC-11.03.002: Forbidden Dark Pattern — Pay-to-Win in Ranked Mode (DP-004)

## Description

Defines the machine-checkable assertion that no spend tier provides any
mechanical advantage (higher combat power, faster progression, greater
accuracy, improved stats) over a zero-spend player in any ranked or
competitive game mode. This is DP-004: pay-to-win in ranked. The assertion
is evaluated against the economy graph (CAP-005 artifact) by verifying that
the combat-power distribution across all spend tiers is flat within a declared
epsilon in ranked-mode contexts. A cosmetics-only ethics contract requires
epsilon = 0: perfect flatness. This BC ties CAP-011's ethics enforcement to
CAP-006's simulation verification substrate.

## Preconditions

1. The game declares at least one ranked or competitive mode
   (`game_modes` contains a mode with `ranked: true` or `competitive: true`).
2. An `economy-graph` artifact exists for this game_id (CAP-005 output).
3. `monetization-ethics-contract.no_p2w_in_ranked == true` (default envelope
   sets this as the default; custom contracts may not weaken it for ranked
   modes without adversarial review).
4. The economy simulation can evaluate combat-power distributions per spend
   tier for a ranked game-mode context.

## Postconditions

1. **PASS (cosmetics-only or explicit epsilon=0):** For all spend tiers
   `t ∈ [0, max_spend]`, the combat power `CP(t)` in ranked mode satisfies
   `|CP(t) - CP(0)| <= ε` where ε is declared in the ethics contract.
   For cosmetics-only (`ethics_contract.p2w_epsilon_ranked = 0.0`), this
   means strict equality within floating-point tolerance.
2. **FAIL (P2W detected):** For any spend tier `t > 0`, `CP(t) - CP(0) > ε`
   in any ranked or competitive mode context. Error: **E-ETH-011**
   (`error.data.reason: PAY_TO_WIN_IN_RANKED_DETECTED`) with the spend tier,
   measured gap, and declared epsilon.
3. **NOT APPLICABLE:** Game has no ranked/competitive modes. BC does not apply.
   PASS-EXEMPT recorded; not a convergence issue.
4. **EPSILON WEAKENED WITHOUT REVIEW:** Ethics contract custom variant sets
   `p2w_epsilon_ranked > 0` but adversarial review check A-02 has not been
   completed. Warning emitted: `P2W_EPSILON_WEAKENING_NOT_REVIEWED`.

## Invariants

1. The no-P2W assertion is evaluated for ALL spend tiers, not just comparing
   max-spend vs zero-spend. An intermediate tier that is stronger than both
   free and max-spend would also fail (though this would be an unusual
   economy design).
2. "Ranked mode" includes any mode where player performance is recorded on a
   leaderboard, affects matchmaking tier, or is used for competitive standing.
   A "friendly ranked" mode still triggers this check.
3. Temporary power-up consumables in ranked mode are not exempt by virtue of
   being "limited time." If a consumable provides mechanical advantage in
   ranked mode and is purchasable with real money, it is a P2W item.
4. The default envelope (`no_p2w_in_ranked: true`) cannot be relaxed by
   a custom contract without adversarial review sign-off. This invariant
   protects against post-review contract edits that quietly introduce P2W.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Cosmetics (skins, emotes) that have no stat effect | PASS. Cosmetics are explicitly the "ethical" model (monetization-business-model.md §4.3). |
| EC-002 | Stat-boosting item available in ranked for free AND for purchase (both paths give identical power) | PASS. The stat boost is available to all regardless of spend; spend only gives the item faster. This is a "convenience vs power" distinction but the power itself is equal. |
| EC-003 | Purchasable item provides +5 HP in ranked; HP is declared as a combat-power metric | FAIL: E-ETH-011 (`PAY_TO_WIN_IN_RANKED_DETECTED`). Even small mechanical advantages are flagged. The threshold is set by `p2w_epsilon_ranked`; default is 0. |
| EC-004 | Game has a "casual" unranked mode where P2W items are permitted and a separate "ranked" mode where they are not | PASS for ranked mode. P2W check is mode-scoped. Casual mode P2W is a business decision not covered by this BC (but may be flagged as DP-007 / fairness concern in adversarial review). |
| EC-005 | Battle pass that unlocks a ranked power item behind 40 hours of grind (non-payer can earn it) | If the item is genuinely earnable without spend (free path exists per BC-11.02.003), it is not P2W. The earning time disparity is a design choice. |
| EC-006 | XP booster that allows payers to unlock the same items faster but all items are eventually available free | If all items are equippable in ranked by non-payers before their rank decays significantly, this is a grind differential, not P2W. Requires `no_progression_deadlock_without_spend` check to confirm. |
