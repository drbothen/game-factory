# BC-11.01.002: Default Ethics Envelope Application

## Description

Defines the behavior of the default ethics envelope — the factory's pre-built
conservative policy that is automatically applied when monetization is present
but no custom `monetization-ethics-contract` has been authored. The default
envelope is the strictest safe starting point (premium/cosmetic-only, no
gacha, no loot boxes, no energy timers, 1 prompt per session). It is not a
substitute for a reviewed custom contract; its presence keeps the pipeline
from FAILING but holds convergence dimension #10 in an amber (not GREEN)
state until a custom human-reviewed contract replaces it.

## Preconditions

1. `business-model-spec.archetype != "premium_only"` (monetization is active).
2. No custom `monetization-ethics-contract` artifact exists for this game_id.
3. The factory pipeline is at the ethics gate evaluation step.

## Postconditions

1. **DEFAULT APPLIED:** The factory synthesizes a `monetization-ethics-contract`
   with `authored_by_human: false`, `is_default_envelope: true`, and the
   canonical default field values (see §11.2.3 of PRD supplement). The
   pipeline does NOT fail; it proceeds with all mechanics restricted to
   `["premium_purchase", "cosmetic_dlc"]`.
2. **CONVERGENCE AMBER:** Convergence dimension #10 is set to AMBER (not
   GREEN, not BLOCKED). The amber state note reads: "Default ethics envelope
   applied. Custom human-authored contract required for GREEN. Gacha, loot
   boxes, energy timers, and F2P mechanics cannot be used until a reviewed
   custom contract replaces the default."
3. **MECHANIC GATING:** Any generated monetization artifact that specifies a
   mechanic outside the default allow-list (`["premium_purchase", "cosmetic_dlc"]`)
   is rejected with error `MECHANIC_NOT_PERMITTED_BY_DEFAULT_ENVELOPE`. The
   `monetization-designer` agent must obtain a custom ethics contract before
   generating restricted mechanics.
4. **CUSTOM CONTRACT ARRIVAL:** When a human-authored, structurally valid
   custom ethics contract is created (BC-11.01.001 PASS), the default envelope
   is superseded. The supersession is logged with a timestamp. Convergence
   dim-10 advances from AMBER to the adversarial review gate.

## Invariants

1. The default envelope ALWAYS permits `premium_purchase` and `cosmetic_dlc`.
   These two mechanics are unconditionally safe under the default policy.
2. The default envelope NEVER permits gacha, loot boxes, energy timers,
   loss-triggered offers, or F2P IAP beyond cosmetic. Permitting these
   requires a custom contract.
3. The default envelope is never shipped as the final reviewed ethics contract.
   Its `authored_by_human: false` field ensures this: any pipeline that reaches
   a ship decision with the default envelope as the active contract is BLOCKED.
4. Supersession is one-way: once a custom contract replaces the default, the
   default cannot be re-applied without explicitly archiving the custom contract.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Game starts with default envelope; `monetization-designer` attempts to generate `gacha-spec` | Generation rejected: `MECHANIC_NOT_PERMITTED_BY_DEFAULT_ENVELOPE`. Generator is told it needs a custom ethics contract with gacha in allow-list. |
| EC-002 | Custom contract arrives but is structurally invalid (BC-11.01.001 returns INVALID) | Default envelope remains active. Convergence dim-10 stays AMBER. Pipeline returns `CUSTOM_CONTRACT_INVALID`; default envelope not superseded. |
| EC-003 | Custom contract arrives, is valid, but `adversarial_review_evidence_ref` is null | Contract supersedes default; dim-10 advances from AMBER to the adversarial review gate (BC-11.01.003). Not yet GREEN. |
| EC-004 | Two custom contracts arrive in the same pipeline burst | The one with the later timestamp supersedes. If timestamps are equal, `ETHICS_CONTRACT_AMBIGUOUS` error; human must resolve. |
| EC-005 | Game has `archetype: "premium"` but a DLC is added that includes a cosmetic shop | Default envelope fires for the cosmetic shop addition. Premium exemption only applies to zero-monetization games. Any shop triggers the ethics gate. |
| EC-006 | Ship decision attempted with `is_default_envelope: true` on active contract | Pipeline BLOCKED: `CANNOT_SHIP_WITH_DEFAULT_ENVELOPE`. This is treated equivalently to E-ETH-001 (`ETHICS_CONTRACT_ABSENT`) for ship purposes. |
