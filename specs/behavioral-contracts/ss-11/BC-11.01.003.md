# BC-11.01.003: Adversarial Review Evidence Gate (Fail-Closed for Convergence)

## Description

Defines the gate that keeps convergence dimension #10 (monetization-ethics)
from being GREEN until a structurally valid `monetization-ethics-contract`
has been subjected to at least one complete adversarial review pass and the
evidence artifact for that review exists and is non-null. This gate is
fail-closed: absence of review evidence is treated as BLOCKED, not DEGRADED.
It is the monetization analog of the 3-clean-passes-to-convergence rule
inherited from vsdd-factory adversarial review.

## Preconditions

1. `monetization-ethics-contract` is structurally valid (BC-11.01.001 PASS).
2. The custom contract has superseded the default envelope (BC-11.01.002
   supersession has occurred).
3. Convergence dimension #10 is being evaluated (not in amber/default-only state).
4. An adversarial review agent has been dispatched against the contract.

## Postconditions

1. **BLOCKED (no evidence):** `adversarial_review_evidence_ref` is null or
   references a non-existent artifact. Convergence dimension #10 remains
   BLOCKED. Error emitted: `MONETIZATION_ETHICS_ADVERSARIAL_REVIEW_REQUIRED`.
   The adversarial review agent has not been dispatched or has not yet
   completed.
2. **BLOCKED (open findings):** Review evidence exists but the adversarial
   review artifact contains one or more `status: open` findings of severity
   `critical` or `important`. Dimension #10 remains BLOCKED with a summary
   of open findings.
3. **GREEN (clean pass):** Review evidence exists, references a completed
   adversarial review artifact, and all critical/important findings are
   `status: resolved`. Dimension #10 transitions from BLOCKED to GREEN for
   the adversarial review sub-gate. (Full GREEN requires all other CAP-011
   assertions also passing — see §11.10 of PRD supplement.)
4. **STALE EVIDENCE:** Review evidence exists but the contract has been
   modified since the review was completed (contract `modified_at` timestamp
   is newer than review `completed_at` timestamp). Dimension #10 reverts to
   BLOCKED with error `MONETIZATION_ETHICS_CONTRACT_MODIFIED_SINCE_REVIEW`.
   Re-review required.

## Invariants

1. Convergence dimension #10 can NEVER be GREEN with a null
   `adversarial_review_evidence_ref`. This is the machine-enforceable
   expression of the brief's "adversarial review of `monetization-ethics-contract`
   mandatory" constraint.
2. Contract modification after review always invalidates the review evidence.
   The gate re-triggers on any field change in the contract. This prevents
   post-review edits that introduce violations.
3. At least one adversarial review pass must be explicitly completed — not
   just dispatched. A dispatched but incomplete review does not satisfy the
   gate.
4. The adversarial review checks are specified in §11.6 of the PRD supplement
   (A-01 through A-07). The review artifact must confirm each check was
   evaluated.

## Edge Cases

| ID | Description | Expected Behavior |
|----|-------------|-------------------|
| EC-001 | Adversarial review dispatched but agent times out or returns no output | BLOCKED; evidence ref points to a timed-out artifact; status = `review_incomplete`; re-dispatch required |
| EC-002 | Review completes with all findings `status: suggestion` (no critical/important) | GREEN for adversarial sub-gate; suggestion-level findings are recorded but do not block |
| EC-003 | Contract modified by fixing an adversarially found issue (legitimate edit) | Review evidence is invalidated; BLOCKED until re-review. This is correct behavior — every version of the contract that ships needs its own reviewed evidence. |
| EC-004 | Two adversarial review passes exist; the second is clean but the first had open findings | The most recent completed clean pass satisfies the gate. Historical passes are retained in audit log but do not affect gate state. |
| EC-005 | `adversarial_review_evidence_ref` points to a different game's review artifact | BLOCKED: `REVIEW_EVIDENCE_GAME_ID_MISMATCH`. Review artifacts are game-scoped and cannot be reused across games. |
| EC-006 | Review evidence exists but adversarial review artifact is missing from the filesystem | BLOCKED: `REVIEW_EVIDENCE_ARTIFACT_NOT_FOUND`. Reference without artifact is treated as null. |
| EC-007 | Contract is premium-only (no ethics contract required per BC-11.01.001 EC-001) | Adversarial review gate does not fire; not applicable. |

## Canonical Test Vectors

| Input | Expected Output | Category |
|-------|----------------|----------|
| Valid contract, `adversarial_review_evidence_ref: null` | dim-10 BLOCKED: `MONETIZATION_ETHICS_ADVERSARIAL_REVIEW_REQUIRED` | error (no review) |
| Valid contract, review evidence present, 0 critical/important findings | dim-10 adversarial sub-gate = GREEN | happy-path |
| Valid contract, review evidence present, 1 open `important` finding | dim-10 BLOCKED: open finding listed | error (open findings) |
| Valid contract, clean review, contract then modified | dim-10 BLOCKED: `MONETIZATION_ETHICS_CONTRACT_MODIFIED_SINCE_REVIEW` | edge-case (staleness) |
| Review evidence ref points to wrong game_id | dim-10 BLOCKED: `REVIEW_EVIDENCE_GAME_ID_MISMATCH` | error (mismatched ref) |
